AONANG LANDMARK BOXING STADIUM — WEBSITE
========================================

ไฟล์ในชุดนี้
- index.html : เว็บไซต์หลัก (Home, Live, Fight Schedule, Training, Gallery, Contact)
- booking.html : หน้าจองบัตรเข้าชมและคลาสฝึกมวยไทย
- style.css : ดีไซน์ responsive โทนดำ-แดง-ทอง รวมหน้า Booking
- script.js : เมนูมือถือ ตัวกรองรายการ และแบบฟอร์มติดต่อ
- booking.js : ผังเลือกที่นั่งหลายที่ สรุปราคา และแบบฟอร์มจองคลาสฝึกในหน้า Booking
- language.js : สลับภาษาไทยและอังกฤษในทั้งสองหน้า
- gallery.js : ภาพสไลด์ ตัวกรองหมวด และปุ่มควบคุม Gallery
- Google Maps และปุ่ม WhatsApp สำหรับติดต่อสอบถาม
- BG.jpg : ภาพพื้นหลังสนามมวย
- logo.jpg : โลโก้แสดงบนหัวและท้ายเว็บไซต์

วิธีเปิด
1. เปิด index.html ด้วยเว็บเบราว์เซอร์
2. เลือก Booking จากเมนู หรือกดปุ่มจองบนหน้าแรก

ก่อนเปิดใช้งานจริง
- เปลี่ยนวันแข่งขัน คู่ชก และราคาใน booking.html ให้เป็นข้อมูลจริง
- เชื่อมต่อฟอร์ม Booking และ Contact กับระบบรับข้อมูล/ชำระเงิน
- เปลี่ยนเบอร์โทร อีเมล และลิงก์โซเชียลเป็นข้อมูลของสนาม
- เชื่อมต่อระบบถ่ายทอดสดจริงในส่วน Live
- ตรวจสอบสิทธิ์ภาพประกอบ และใช้ภาพของสนามที่ได้รับอนุญาต

ผังที่นั่งและสถานะว่าง/ไม่ว่างเป็นข้อมูลสาธิต ไม่ได้อ้างอิงที่นั่งจริง และไม่ได้กันที่นั่งไว้
การส่งแบบฟอร์มเป็นคำขอเพื่อสาธิต ไม่ใช่การยืนยันการจองหรือการชำระเงิน หากติดตั้ง API พร้อม KV แล้ว ระบบจะบันทึกคำขอไว้ให้ผู้ดูแลตรวจสอบ แต่ยังไม่ยืนยันที่นั่งหรือรับชำระเงิน หาก API ใช้งานไม่ได้ ระบบจะเก็บคำขอไว้เฉพาะในเบราว์เซอร์นั้น
ยืนยันวันแข่งขัน ราคา และที่นั่งว่างกับสนามก่อนเปิดรับจองจริง ผังที่นั่งที่แนบมากับบทสนทนาเดิมไม่อยู่ในไฟล์ที่ได้รับ จึงใช้ผังตัวอย่างแทน
ภาพประกอบบางภาพโหลดจาก Unsplash ผ่านอินเทอร์เน็ต

ภาพนักชกสำหรับการ์ดคู่เอกและคู่รอง: MP BLUE.jpg, MP RED.jpg, CO BLUE.jpg และ CO RED.jpg
Gallery แสดงภาพแบบสไลด์ มีปุ่มเลื่อน จุดเลือกภาพ ตัวกรองหมวด และเล่นอัตโนมัติ
ภาพ Fight Night เพิ่มเติมอยู่ใน Gallery/Fight night/G1.jpg–G6.jpg และแสดงเป็นภาพสไลด์
หมวด FIGHT NIGHT แสดงเฉพาะภาพ G1–G6 จากโฟลเดอร์ Gallery/Fight night
หมวด STADIUM แสดงเฉพาะภาพ ST1–ST6 จากโฟลเดอร์ Gallery/Stadium
หมวด TRAINING แสดงเฉพาะภาพ TR1–TR6 จากโฟลเดอร์ Gallery/Traning โดยนำภาพตัวอย่างออกแล้ว

- dashboard.html : แดชบอร์ดจัดการตารางแข่งขันและคำขอจอง (ข้อมูลเก็บในเบราว์เซอร์)
- dashboard.css / dashboard.js : ส่วนติดต่อและการจัดการแดชบอร์ด

- site-data.js : แสดงตารางแข่งขันที่จัดการจากแดชบอร์ด

แดชบอร์ดจัดการรูปนักชก UPCOMING FIGHTS และภาพ FIGHT NIGHT GALLERY ได้ รูปที่อัปโหลดเก็บใน localStorage ของเบราว์เซอร์

ระบบจัดการรูปภาพในแดชบอร์ดรองรับ UPCOMING FIGHTS, FIGHT NIGHT, TRAINING และ STADIUM

- login.html : หน้าเข้าสู่ระบบและตั้งค่าบัญชีผู้ดูแลครั้งแรก
ข้อจำกัดความปลอดภัย: ระบบ Login นี้ทำงานฝั่งเบราว์เซอร์ ยังไม่ใช่การยืนยันตัวตนบนเซิร์ฟเวอร์ ไม่ควรใช้ปกป้องข้อมูลสำคัญบนเว็บไซต์สาธารณะ

ระบบลืมรหัสผ่านใช้รหัสกู้คืนที่แสดงครั้งเดียวหลังตั้งบัญชีหรือเข้าสู่ระบบครั้งแรก และจะออกชุดใหม่หลังรีเซ็ตรหัสผ่าน

ระบบลืมรหัสผ่าน: กด “ลืมรหัสผ่าน? ใช้รหัสสำรอง” แล้วกรอกชื่อผู้ใช้ รหัสสำรอง และรหัสผ่านใหม่ รหัสสำรองแสดงครั้งเดียวหลังตั้งบัญชี/เข้าสู่ระบบครั้งแรก และจะเปลี่ยนหลังรีเซ็ต


อัปเดตระบบ Booking (Premium Seat Map)
- ผังเลือกที่นั่งตามกลุ่มที่นั่งสนาม: Ringside S1-S75 ราคา 1,800 บาท
- VIP SEAT A1-H18 ราคา 1,200 บาท
- GRAND STAND GT1-GT80 ราคา 1,000 บาท
- เลือกได้หลายที่นั่ง (สูงสุด 10) และสรุปราคารวมอัตโนมัติ
- อัปเดต API validation ให้ตรวจรหัสที่นั่ง ประเภท และราคาให้ตรงกับผังใหม่
- คงระบบภาษาไทย/อังกฤษ เมนู และสไตล์หลักของเว็บไซต์
หมายเหตุ: ผังบนหน้า Booking เป็นผังเวกเตอร์ที่จัดตำแหน่งตามภาพอ้างอิงที่เคยให้ไว้ ไม่ใช่การยืนยันผังหรือสถานะที่นั่งแบบเรียลไทม์


ระบบล็อกที่นั่ง (Seat Locking) — รุ่นเริ่มต้น
- เมื่อลูกค้าส่งคำขอจอง Fight Night ระบบจะขอล็อกที่นั่งที่เลือกไว้ 15 นาที
- ใช้ Cloudflare D1 เพื่อเก็บสถานะล็อกส่วนกลาง ไม่ใช้ localStorage เป็นแหล่งตัดสินสถานะ
- ที่นั่งที่ถูกล็อกโดยลูกค้ารายอื่นหรือยืนยันจองแล้วจะถูกปิดไม่ให้เลือก
- เมื่อครบเวลา 15 นาที รายการล็อกหมดอายุและจะกลับมาเลือกได้อัตโนมัติเมื่อหน้าเว็บรีเฟรชสถานะ
- ผู้ดูแล/ระบบชำระเงินสามารถยืนยันการจองได้ผ่าน POST /api/seat-locks ด้วย action=confirm, date และ lockToken โดยต้องส่ง Authorization: Bearer <FIGHTS_ADMIN_TOKEN>
- ยกเลิกล็อกได้ด้วย action=release และ lockToken

การตั้งค่าที่จำเป็นก่อนเปิดใช้งาน:
1. สร้าง Cloudflare D1 database แล้วผูก binding ชื่อ SEAT_LOCKS_DB กับ Pages Functions ของเว็บไซต์
2. รัน SQL ใน migrations/0001_seat_locks.sql กับ D1 database
3. ตรวจสอบว่ามี binding fights_kv เดิมสำหรับ API คำขอจอง และตั้งค่า FIGHTS_ADMIN_TOKEN เป็น secret
4. Deploy Pages Functions ใหม่ แล้วทดสอบ /api/seat-locks?date=YYYY-MM-DD
5. ระบบรับชำระเงินยังไม่ได้เชื่อมต่อ Payment Gateway ในชุดนี้: การล็อก 15 นาทีทำงานได้หลังตั้งค่า D1 แต่การยืนยันชำระเงินจริงต้องเชื่อม webhook ของผู้ให้บริการชำระเงิน แล้วเรียก action=confirm ด้วย token ฝั่งเซิร์ฟเวอร์เท่านั้น

หมายเหตุด้านความปลอดภัย:
- อย่าใส่ FIGHTS_ADMIN_TOKEN ใน JavaScript ฝั่งเบราว์เซอร์
- การล็อกเป็นแบบต่อวันแข่งขันและรหัสที่นั่ง (event_date + seat_id)
- ระบบจะไม่เก็บข้อมูลบัตรเครดิต และไม่ควรรับเลขบัตรผ่านแบบฟอร์มนี้


CLOUDFLARE PAGES DEPLOYMENT NOTE
- Pages Functions must be located in the root-level `functions/` directory. This package has been arranged accordingly.
- Keep `functions/api/` at the repository root beside `index.html` and `booking.html`.
- Bind the D1 database using variable name `SEAT_LOCKS_DB`.
- Run `migrations/0001_seat_locks.sql` against the D1 database before enabling the booking API.
